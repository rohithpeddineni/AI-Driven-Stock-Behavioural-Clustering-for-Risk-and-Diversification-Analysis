# Final Project Report Package

This directory contains the final academic report package for **AI-Based Stock
Behavioural Clustering for Risk Analysis**.

## Files

- [final_report.md](final_report.md): complete academic report.
- [presentation_outline.md](presentation_outline.md): slide-by-slide presentation plan.
- [figure_references.md](figure_references.md): figure captions and source paths.
- [key_results.csv](key_results.csv): compact table of reported results.

The report is based on the completed final-validation outputs in
`../final_validation/`. No experiments are rerun by this report package.
